Gerenciador de Conexão com API do Movidesk

Insira a URL e a Chave de API (Token) do seu Movidesk para baixar automaticamente todos os chamados, apontamentos e equipes da empresa.

Exemplo: https://minhaempresa.movidesk.com
Obtenha em: Configurações > Integrações > Chaves de API no Movidesk.

Como interpretar os indicadores

Busca Unificada OData Movidesk: Extrai todos os chamados, equipes (`ownerTeam`), serviços (`serviceFirstLevel`) e apontadores de horas (`actions.createdBy`).

Regra de 80% (6,4h): Considera a margem de tolerância para pausas e reuniões.
