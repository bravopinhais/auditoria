Configuração da API Movidesk

Insira o seu token da API do Movidesk para permitir a sincronização com o banco de dados.

Obtenha este token no Movidesk em: Configurações > Integrações > API Web.

Como interpretar os indicadores

Pendentes: usa a view v_audit_pending_tickets, que exclui status reconhecidos como encerrados, concluídos, resolvidos ou cancelados.

Clientes prioritários: lista cadastrada de 10 clientes (Dr Óculos, Ferri, Instituto, Paulo e Condah, Atacadão do Óculos, IMV, Paschoal LAB, Cardeal, Sr dos Óculos, Lux).

Segurança: o HTML usa chave publicável e autenticação Supabase. Nunca coloque chaves secretas no navegador.
